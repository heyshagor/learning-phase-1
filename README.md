# Phase 1 Learning Plan

A comprehensive 16-week study plan designed to build foundational skills in networking, Python programming, data structures & algorithms, and project development.

## Overview

This learning plan spans **4 months** with approximately **1.5 hours per day on weekdays** and **3 hours on weekends**. The curriculum is structured to provide a balanced approach to learning core technical concepts through progressive weekly modules.

## Curriculum Topics

The plan covers five main topic areas:

- **Networking** (Blue) - Internet fundamentals, OSI model, TCP/IP, IP addressing, and subnetting
- **Python** (Green) - Programming fundamentals, syntax, and practical coding skills
- **DSA** (Purple) - Data structures and algorithms, Big-O notation, and problem-solving
- **Project** (Orange) - Hands-on project work to apply learned concepts
- **Review** (Gray) - Weekly consolidation and knowledge reinforcement

## Using the Interactive Plan

The `phase1_week_by_week_plan.html` file is a fully interactive web application:

### Features

- **Weekly breakdown**: Click on any week to expand and see daily tasks
- **Progress tracking**: Check off completed weeks to track your progress
- **Month navigation**: Filter view by month using the month buttons
- **Color-coded topics**: Each topic area has its own color for easy identification
- **Resource links**: Some weeks include buttons to generate prompts for explanations

### How to Use

1. Open `phase1_week_by_week_plan.html` in any modern web browser
2. Click on a week card to expand/collapse and view daily tasks
3. Check the checkbox when you complete a week
4. Use the month buttons (Month 1-4) to filter by month
5. Watch the progress bar update as you complete weeks

### Weekly Structure

Each week includes:
- **Week number and title** - The main focus for that week
- **Daily tasks** - Monday through Sunday breakdown
- **Time estimate** - Total hours expected for the week
- **Resource suggestions** - Free online resources and tutorials
- **Interactive prompts** - Some weeks have AI assistant prompts for explanations

## Weekly Topics Preview

### Month 1: Foundations
- **Week 1**: How the internet actually works (OSI model, TCP/IP, Python setup)
- **Week 2**: IP addresses & subnetting
- **Week 3**: Network protocols & Python basics
- **Week 4**: DNS, HTTP, and Python data types

### Month 2: Core Programming & Basic Algorithms
- **Week 5**: Python control flow and list operations
- **Week 6**: DSA fundamentals (arrays, linked lists)
- **Week 7**: Stacks, queues, and recursion
- **Week 8**: Mid-term review and mini-project

### Month 3: Advanced Data Structures
- **Week 9-12**: Trees, graphs, hash tables, sorting algorithms

### Month 4: Integration & Projects
- **Week 13-16**: Capstone projects, system design basics, final review

## Getting Started

1. **Clone or download** this repository
2. **Open** `phase1_week_by_week_plan.html` in your browser
3. **Start with Week 1** and follow the daily tasks
4. **Check off** completed weeks to track progress

## Tips for Success

- **Consistency is key**: Try to maintain the daily schedule rather than cramming
- **Hands-on practice**: Python and DSA topics require writing actual code
- **Take notes**: Use the review days to consolidate learning
- **Don't skip weeks**: Each week builds on previous knowledge
- **Use free resources**: The plan references freely available online materials
